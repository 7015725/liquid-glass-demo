# 变量规范与使用指南

本文分两部分：第 1–6 节是**规范**（语法、作用域、类型、时机、各调用点的确切行为），第
7–9 节是**使用指南**（怎么选、常见写法、排错）。输出变量的元数据与矩阵另见
[`output-variables.md`](output-variables.md)，JavaScript 沙箱细节另见
[`javascript-script-action.md`](javascript-script-action.md)。

## 1. 三类变量

界面上能看到的变量分三类（系统、局部、全局），另有 `run`、`event` 两个运行期内部域。
所有变量都是**名字 → 值**，值有类型（§4）。

| 类别 | 谁提供 | 生命周期 | 可写 |
| --- | --- | --- | --- |
| 系统变量 · 内置 | 引擎，目前只有「上一步结果」 | 单次运行 | 否 |
| 系统变量 · 输出 | 触发器/动作实例，名字在组件输出页配置 | 单次运行 | 否 |
| 局部变量 | 每条指令自己的 `locals` | 按「运行后保留」 | 是 |
| 全局变量 | 跨指令共享 | 跨指令持久 | 是 |
| `run`（内部） | 运行期临时值，如 `run.last` | 单次运行 | 是 |
| `event`（内部） | 原始事件键 | 单次运行 | 否 |

- **上一步结果**：每个动作/流程块结束后，值是它的结果摘要；第一个动作之前不存在。
- **输出变量**：没有专属输出的组件会有一个主输出（如「振动结果」），有专属输出的组件按
  schema 生成（如 Shell 的标准输出/错误/退出码、脚本的「脚本结果」）。触发器输出在条件求值
  前就绪，动作输出在该动作完成后就绪。
- **局部变量**：默认属于当前指令，别的指令看不到，也不能在别处引用。
- **全局变量**：所有指令可见；写入后在下一次保存时持久化。

## 2. 语法

### 2.1 基本写法

```
{名字}
```

- 名字按 `VariableName` 校验：1–64 个字符，首字符是字母或 `_`，其余可以是中文、字母、数字、
  `_`、`-`；**不能有空格和点**（点是作用域前缀的分隔符）。
- 编辑器里用参数框右侧的 `{}` 插入变量；列表会按当前位置过滤，只显示此处可见的变量。
- 保存时原样保存，**执行时**才替换；值里即使含有 `{另一个变量}` 也不会二次展开。
- 名字不存在时**保留原文**（`{拼错了}` 原样出现在结果里），不会静默变空串。已存在但值为空串
  的变量会替换成空串，两者不同。

### 2.2 作用域前缀

裸名有默认解析顺序（§3）。需要明确指定时：

| 写法 | 指向 |
| --- | --- |
| `{rule.名字}` | 当前指令的局部变量 |
| `{global.名字}` | 全局变量 |
| `{run.名字}` | 运行期临时变量 |
| `{event.名字}` | 原始事件键（只读，一般不用） |

- 前缀只认这四个；`{http.body}`、`{global.a.b}` 这种不是变量，保持字面量（第二个点也不认）。
- 前缀后的名字同样允许中文，所以 `{global.城市}` 可用。

### 2.3 转义与旧写法

- `{{名字}}` 在会展开的位置输出字面量 `{名字}`，不展开；JavaScript 字符串本身不展开，原样保留。
- 旧写法 `%{名字}`、`%{global.名字}` 仍然可用，规则与 `{...}` 相同；新内容建议统一写 `{...}`。
- Shell 的 `${VAR}` 是 shell 自己的参数展开，不会被当成变量 token。

### 2.4 哪里会展开、哪里不会

| 位置 | 行为 |
| --- | --- |
| 动作参数、条件字段、通知正文 | 展开 |
| HTTP 请求的 URL 段 | 展开并做百分号编码；正文不编码 |
| Shell 命令（含单引号、双引号、未加引号的 heredoc 正文） | 展开，见 §5.2 |
| JavaScript 代码位置 | 展开为只读绑定，见 §5.3 |
| JavaScript 字符串、注释、模板字符串的**文字部分** | 不展开，保持字面量 |
| 模板字符串的 `${ ... }` 内部 | 按代码展开 |
| Shell 中带引号的 heredoc 定界符（`<<'EOF'`） | 不展开 |

## 3. 同名与解析顺序

保存期会阻止内置、输出、局部、全局之间的重名，正常规则不会出现歧义。运行期的兜底顺序是：

```
local → global → builtin → output → run
```

- 显式前缀永远优先，不受同名影响。
- 旧文件或手工改过的文件才可能同名；排错时按上面的顺序判断，或直接改用前缀。
- 自动指令的**顶层条件**在规则执行器之外求值：取值表是「持久变量（局部遮蔽同名全局）+ 本次
  事件输出」，同名时事件输出盖过持久变量；规则体内部仍按上面的顺序。详见
  [`output-variables.md`](output-variables.md) §5.5。

## 4. 类型

六种类型：整数、真假、文本、整数列表、真假列表、文本列表。

- **文本化**（插入参数、Shell、URL 时）：真假 → `true` / `false`；列表 → 逗号连接；null →
  空串。
- **真假解析**接受：`true`、`false`、`真`、`假`、`1`、`0`、`是`、`否`（忽略大小写和首尾空白）。
- **整数解析**只接受整数；小数、空串、非数字会报「不是整数」，动作失败。
- **列表解析**：逗号或换行分隔，也接受 `[1,2,3]` 这种 JSON 数组写法；空串是空列表。
- **JavaScript 映射**：整数 → number，真假 → boolean，文本 → string，列表 → 数组。

## 5. 各调用点

### 5.1 动作参数

- 每个参数按自己的展开方式处理：普通文本原样替换，HTTP 请求只对 URL 段做百分号编码、正文保持原样。
- 未知名字保留 `{名字}`，方便发现拼写错误。
- 单次展开：`A` 的值是 `{B}` 时，`{A}` 只变成 `{B}`，不会继续变成 B 的值。

### 5.2 Shell（Root Shell）

- 变量值**不会**拼进命令文本。展开器先在命令前生成赋值前导：

  ```sh
  FG_V1='值'
  ```

  命令里只保留引用，如 `"${FG_V1}"`。值里的单引号会被转义，所以 `'`、`"`、`$()`、反引号、
  换行都不会被当成命令语法执行。
- 引用形式随上下文选择：
  - 未加引号 → `"${FG_V1}"`
  - 双引号内 → `${FG_V1}`
  - **单引号内也会展开** → `'"${FG_V1}"'`（先闭合单引号，再双引号展开，再恢复单引号）
- 未加引号的 heredoc 正文会展开；`<<'EOF'` / `<<"EOF"` 的正文不展开。
- 未知名字保持 `{名字}` 字面量，交给 shell。
- `${VAR}`、`$?` 等 shell 自身的写法不受影响。

### 5.3 JavaScript（Rhino 沙箱）

- 脚本开始时，所有变量以**只读**属性绑定；`{名字}` 在代码位置替换成内部标识符，值通过绑定
  传入，不会拼进源码。字符串、注释、模板字符串的文字部分不替换。
- 模板字符串按 JavaScript 语义处理：`${ {变量} }` 会展开，支持嵌套模板、对象字面量、注释。
- `get(name)`：读取当前值；未知名字返回 `null`；支持 `rule.` / `global.` / `run.` / `event.`
  前缀，裸名按 §3 的顺序。
- `set(name, value)`：
  - 裸名：已存在的局部 → 写局部；否则已存在的全局 → 写全局；都没有 → **新建局部变量**
    （默认运行后不保留）。
  - `global.x`：新建或更新全局；`run.x`：运行期临时值。
  - 内置、输出、`event.` 只读，写入会报「…只读，不能修改」。
  - 已存在的变量保持声明类型；新变量按 JS 值推断（布尔 → 真假，整数 → 整数，数组 → 对应
    列表，其余 → 文本）。类型不匹配（如把 `"abc"` 写进整数）会让动作失败。
- `{名字}` 绑定是**脚本开始时的快照**：同一脚本里 `set("global.全局", "新值")` 之后，
  `{global.全局}` 仍是旧值，`get("global.全局")` 才是新值；下一个动作里的 `{global.全局}`
  才是新值。
- 未知 `{名字}` 不会被替换，会作为 JavaScript 源码交给 Rhino，通常报语法错误或
  `ReferenceError`。不确定名字是否存在时用 `get()`。
- 脚本最后表达式的值写入「脚本结果」输出（截断 4000 字符）。
- 编辑器里的「运行」是隔离试跑，没有变量上下文：`get()` 返回 `null`，`{名字}` 不展开。

### 5.4 条件、URL 与通知

- 条件字段与动作参数同一套 `{...}` 语法、同一套解析顺序；输出变量在条件里只读。
- URL 与 HTTP：HTTP 请求只对 URL 段做百分号编码（空格 → `%20`，中文按 UTF-8 编码），正文不编码。
- 通知正文按普通文本展开；标题不能含 `|`（保存期限制，与变量无关）。

## 6. 生命周期与时机

一次运行的时间线：

1. **开始**：读取全局变量；局部变量用声明的初值初始化。
2. **每一步之后**：写入「上一步结果」；发布该组件的输出变量。
3. **结束**（成功或失败）：写回全局变量；`resetEachRun = false` 的局部变量把当前值存为新
   初值，下次运行从这里开始；`resetEachRun = true` 的不写回，下次仍用声明初值。
4. **手动停止**：不写回任何变量。

补充：

- 「设置变量」或脚本 `set()` 新建的局部变量默认 `resetEachRun = true`（运行后不保留）：
  新建时把当时的值记作初值，下次运行从这个初值开始，之后的写入不会写回。需要保留后续写入时，
  在「设置变量」里把「运行后保留」设为开启，或在变量管理里改。
- 全局变量只有被写入才更新，读取不会产生写入。
- 取消的运行不会持久化半成品变量。

## 7. 怎么选

- **只是本步骤算一下、下一步用**：局部变量，或直接用「上一步结果」。优先「上一步结果」，
  少建变量。
- **同一条指令里多处使用、需要初值/类型**：建局部变量；需要跨运行记住就关闭「运行后不保留」。
- **多条指令共享（开关、计数、配置）**：全局变量。名字尽量带业务前缀，如 `夜间模式`、
  `今日次数`。
- **只在一次运行内传递、不想被保存**：`run.名字`（脚本）或「设置变量」里新建且不保留的局部。
- **触发器/动作的产出**：用组件输出页给它起一个名字，然后在参数里引用这个名字；不要再用旧
  的共享 key（`http.body`、`script.result` 等）。

## 8. 常见配方

### 8.1 串联上一步

```text
动作 1：HTTP 请求 GET https://api.example.com/status
动作 2：通知正文：上次结果：{上一步结果}
```

### 8.2 全局计数器（脚本）

```js
var n = Number(get("global.次数") || 0) + 1;
set("global.次数", n);
"第 " + n + " 次";
```

### 8.3 全局开关 + 局部覆盖

```text
全局：夜间模式 = false
指令 A：设置变量 夜间模式 = true，保存范围「所有指令」
指令 B：如果 {global.夜间模式} 为真 → 降低亮度
```

不要在指令 B 里再建同名局部变量，否则裸名 `{夜间模式}` 会先命中局部。

### 8.4 Shell 里安全使用带引号的值

```sh
printf '%s\n' "{上一步结果}"
```

值里的 `'`、`"`、`$()`、反引号都不会被执行；单引号里写 `'{上一步结果}'` 也会展开。

### 8.5 JavaScript 模板

```js
`你好 ${ {当前用户} }，共 ${get("run.count") || 0} 条`
```

`{当前用户}` 和 `${...}` 是两件事：前者是变量绑定（只读快照），后者是 JS 表达式。

## 9. 排错清单

| 现象 | 常见原因 | 处理 |
| --- | --- | --- |
| 参数里原样出现 `{名字}` | 名字不存在、拼错、大小写不一致，或被 `{{...}}` 转义 | 用变量选择器插入；核对变量管理里的名字 |
| `{global.名字}` 没展开 | 前缀拼错，或名字里又带了点 | 前缀只认 `rule/global/run/event`，名字不能有点 |
| JS 报 `ReferenceError` / 语法错误 | `{名字}` 不存在，原样进了源码 | 改用 `get("名字")`，或先确保变量存在 |
| JS 里 `{名字}` 是旧值 | 绑定是脚本开始时的快照 | 同脚本用 `get()`；需要新值就放到下一个动作 |
| JS 字符串里的 `{名字}` 没变 | 字符串/注释/模板文字不展开 | 用模板字符串的 `${ {名字} }` 或字符串拼接 |
| `set()` 报「只读」 | 目标是内置、输出或 `event.` | 换一个可写名字，或写 `global.` / `run.` |
| Shell 里 `$名字` 没值 | shell 只认 `$VAR` 形式，不认中文变量 | 写 `{名字}`，由展开器生成 `FG_Vn` |
| heredoc 正文里变量没展开 | 定界符带了引号（`<<'EOF'` / `<<"EOF"`） | 去掉定界符的引号；需要原样文本时不要把变量写进 heredoc |
| 类型报错「不是整数/真假值」 | 变量声明类型与写入值不匹配 | 改类型，或写入合法值（§4） |
| 同名变量取错 | 裸名按 local → global → … 命中 | 改用 `{rule.}` / `{global.}` 明确作用域 |

## 10. 兼容与迁移

- `%{last}` → `{上一步结果}`；`%{rule.x}` / `%{global.x}` 仍可用，但建议改成 `{...}`。
- 旧版共享输出 key（`http.body`、`shell.stdout`、`script.result` 等）不再是变量名；请在组件
  输出页给输出起名，并引用那个名字。
- 重命名变量时，编辑器会同步改写引用：局部变量改本指令内的裸名和 `{rule.}`，全局变量改
  `{global.}` 和未被局部遮蔽的裸名；输出变量改所属指令内的 `{旧名}`。只改 `{...}` 写法，
  旧 `%{...}` 引用需要手工改。
- 变量名区分大小写；`{City}` 与 `{city}` 是两个名字。
